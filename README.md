# Shopify Clone - React JS

A modern Shopify-inspired e-commerce website built using React JS.

## 🚀 Features

- Modern Shopify-inspired UI
- Product Listing
- Category Pages (Men, Women, Kids)
- Shopping Cart Functionality
- Responsive Design
- React Components Architecture
- React Router Navigation
- Clean and Reusable Code

## 🛠️ Tech Stack

- React JS
- JavaScript (ES6+)
- CSS3
- React Router DOM
- Vite

## 📦 Installation

1. Clone the repository

bash
git clone https://github.com/yourusername/shopify-clone.git


2. Navigate to project folder

bash
cd shopify-clone


3. Install dependencies

bash
npm install


4. Run development server

bash
npm run dev
